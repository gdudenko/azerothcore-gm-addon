# GM MINI BAR — русская локализация

**WoW 3.3.5a (12340) · Interface 30300 · Lua 5.1 · AzerothCore**

Русская локализация аддона **GM MINI BAR** (AzerothCore edition) v1.0.0 — GM-инструменты
для администрирования и тестирования приватного сервера в интерфейсе WoW.

## Зачем этот форк

В оригинальном релизе v1.0.0 русский интерфейс был неполным: часть строк
оставалась на корейском. Шрифт аддона (`Fonts/GMminibarUnicode.ttf`) содержит
кириллицу и CJK, но не слоги хангыль, поэтому такие строки отображались как `?`.

В этом форке переведены все отображаемые строки интерфейса, которые удалось
найти аудитом исходников, а названия предметов, существ и заданий заменены
на официальные русские имена из ruRU-локализации AzerothCore. Локализация
сделана патчем файлов аддона на месте, без отдельного аддона-локализатора.

## Что переведено

| Область | Результат |
|---|---|
| Интерфейс | Меню GM, панель удобств, телепорты, карта заданий, справочник команд, браузер предметов, профессии, заклинания, сумки, квест-хелпер, мини-бар, диалоги и подсказки |
| Телепорты | 4 региона, 69 зон, 392 точки назначения, 74 подписи уровня; сложность показывается как «Обычное 10 чел.» / «Эпическое 25 чел.» |
| Справочник команд | 517 команд и 111 групп, названия и описания |
| Данные | 43 256 предметов, 25 300 существ и 9 456 заданий с русскими именами; для остальных — английский fallback |
| Поиск и фильтры | Браузер предметов понимает русские названия классов и типов брони («латы», «кольчуга», «кожа», «ткань», «щит») |

Корейский текст остался только во внутренних матчерах серверных сообщений и
в неиспользуемых таблицах — в интерфейс он не выводится.

## Исправленный баг

В `GMminibar/Modules/ItemBrowser/Module.lua` функция `sourceText()` передавала
в `table.insert` оба значения, которые возвращает `string.gsub` (строку и число
замен). Из-за этого `table.insert` падал с ошибкой
`bad argument #2 to 'insert' (number expected, got string)` для предметов
с непустым полем `raw`.

Исправление — обернуть `gsub` в скобки, чтобы передавалась только строка.
Подробности и минимальный пример: [issue #66](https://github.com/hilch1981-prog/azerothcore-gm-addon/issues/66).

## Установка

1. Скачайте этот репозиторий: **Code → Download ZIP** (или `git clone`).
2. Возьмите папку **`GMminibar`** из корня репозитория.
3. Скопируйте её в `Interface/AddOns` клиента WoW 3.3.5a.
4. Проверьте путь: `Interface/AddOns/GMminibar/GMminibar.toc`.
5. Включите **GM MINI BAR** в списке аддонов и зайдите в игру.
6. Откройте аддон кнопкой **GM Menu** на мини-баре или командой `/aaac`.

Установочный ZIP можно собрать самостоятельно:

```bash
python3 scripts/package.py
# dist/GMminibar_AzerothCore_3.3.5a_v1.0.0.zip
```

Аддон ставится одной папкой `GMminibar`. Не смешивайте файлы с другими
GM-аддонами и не удаляйте `WTF`, если хотите сохранить настройки.

Выбор языка в игре — кнопки в панели настроек (шестерёнка) или команды:

```text
/aaac locale ruRU
/aaac locale auto
```

## Совместимость

- WoW **3.3.5a (12340)**, `## Interface: 30300`, Lua 5.1.
- Сервер **AzerothCore** (WotLK). Номер интерфейса в `.toc` не менялся.
- Для русских имён в подсказках желательны клиент ruRU и серверная БД
  с заполненными таблицами `*_locale`.
- Аддон не предназначен для Classic Era, WotLK Classic или Retail.

## Ограничения

- Серверные сообщения приходят на языке сервера; аддон их не переводит.
- Подсказки предметов, существ и заклинаний формируются клиентом и сервером;
  аддон переводит свои списки и окна, а не весь клиент.
- Автоматические проверки пройдены; окна телепортов, удобств, карты заданий,
  браузера предметов и справочника команд стоит дополнительно проверить в игре
  на вашем сервере и наборе данных.

## Сборка и проверка

```bash
python3 -m pip install lupa==2.8
python3 scripts/validate.py
```

Ожидаемый результат:

```text
PASS Lua 5.1 full TOC load and runtime self-test
PASS: 118 Lua files; 117 TOC entries; XML, version, manifest, package scope
```

`scripts/validate.py` проверяет синтаксис всех Lua-файлов, ссылки из `.toc`
и `.xml`, версию, `FILE_MANIFEST.sha256` и запускает runtime-самотест аддона.
`FILE_MANIFEST.sha256` пересчитан после локализации.

## Структура репозитория

- `GMminibar/` — сам аддон (именно эту папку копируют в клиент).
- `Data/Generated/` — сгенерированные списки предметов, существ, заданий и телепортов.
- `scripts/` — проверка, манифест и сборка установочного ZIP.
- `tests/` — Lua-мок и runtime-самотест.
- `docs/` — документация оригинала (корейская и английская).
